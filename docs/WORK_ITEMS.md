# 작업 우선순위

## 우선 진행

- 실제 운영용 국내 도서 메타데이터와 원출처 준비
- `/admin`, `/api/admin/*` Cloudflare Access 보호 확인
- 원격 D1 migration, secret, Cron 및 배포 상태 검증
- README와 실제 라우트·데이터 흐름의 불일치 정리

## 완료

- GitHub 저장소 연결 및 전체 작업물 버전 관리
- Google Books 연동 코드·설정·문서 제거
- 서울대학교 권장도서 기반 고전 100개를 D1 작품 마스터로 저장

## 고전 데일리 전환 설계

- 활성 단일 작품 82개 중 최근 30일 노출 작품을 우선 제외
- 한국문학·외국문학·동양사상·서양사상·과학기술이 한쪽으로 몰리지 않게 12개 후보 선정
- `classic_editions`에 검증된 판본이 있으면 정보나루 호출 없이 재사용
- 판본이 없는 후보만 정보나루 `srchBooks`로 검색하고 성인용 ISBN을 확인
- 유효 판본 6개를 확보할 때까지 후보를 순차 조회하되 일일 상한은 12개로 제한
- 선정·실패·노출 결과를 `classic_daily_selections`에 저장해 반복과 실패를 추적
- 당일 성공 결과가 6권 미만이면 기존 `classics` 선반을 유지하고 동기화를 실패 처리

## 후순위 — 별도 요청 시 진행

- 클릭률, 저장률, 관심 없음 비율 수집
- 외부 API 지연·오류율과 일일 호출량 측정
- 책 중복, 아동서 및 특정 출판사 편중 모니터링
- 사용자별 추천과 장기 품질 고도화
- 오프라인 PWA service worker
