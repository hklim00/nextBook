# 작업 우선순위

## 우선 진행

- 실제 운영용 국내 도서 메타데이터와 원출처 준비
- `/admin`, `/api/admin/*` Cloudflare Access 보호 확인
- 원격 D1 migration, secret, Cron 및 배포 상태 검증
- README와 실제 라우트·데이터 흐름의 불일치 정리

## 완료

- GitHub 저장소 연결 및 전체 작업물 버전 관리
- Google Books 연동 코드·설정·문서 제거

## 후순위 — 별도 요청 시 진행

- 클릭률, 저장률, 관심 없음 비율 수집
- 외부 API 지연·오류율과 일일 호출량 측정
- 책 중복, 아동서 및 특정 출판사 편중 모니터링
- 사용자별 추천과 장기 품질 고도화
- 오프라인 PWA service worker
